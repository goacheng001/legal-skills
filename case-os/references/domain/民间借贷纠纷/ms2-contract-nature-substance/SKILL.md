# 名实不符合同的性质还原

## R — 原文 (Reading)

> "对于层层嵌套、结构复杂的合同，要坚持实质重于形式，不必强行归类，要以当事人约定为依据准确判断当事人真实意思和真实法律关系，在尊重合同自由的基础上，坚决遏制以复杂交易形式逃避法律规制的所谓'创新'。"
>
> — 第8章 第四节"（一）认定合同性质"（书页160）

## I — 方法论骨架 (Interpretation)

性质还原的四个检验点（按序使用）：

1. **主合同存在性**：让与担保有主从结构，真实转让只有一个合同；同样，"走账协议"若无独立交易目的即为从属性通道安排。
2. **真实交付**：循环贸易的生死线——有无真实货物、有无实际流转交付。"仅有资金流动而并无实际标的物的交付流转"=闭环融资。
3. **对价合理性**：1.5亿存款利息不可能值1.2亿"收益权转让价"；同日签订等量不同价的连环合同、固定价差收益、无仓储费不盘点，均违背商业常理。
4. **履行行为与交易习惯**：交房+收定金→本约成立；放款前/当日付息→砍头息（利息以实际占有资金为前提）。

还原后的处理分岔：虚伪表示（买卖）无效→按隐藏行为（借贷）处理，通道方/仓储方按过错与原因力担责（过桥方=补充赔偿）；预扣利息→按实际出借本金计息；预约→不能强制缔约，赔偿在信赖利益与履行利益之间酌定。

## A1 — 书中的应用 (Past Application)

### 案例 1: 案例库2023-08-2-103-013（融资性贸易过桥方）
- **问题**: 三方无真实货物的购销链，出资方的损失找谁？
- **使用**: 检验点2、3——无实物流转+闭合交易→伪装行为无效、按借贷处理；通道方明知是放款动因、未审合同。
- **结论**: 借款人清偿；过桥方按原因力（间接原因列后）与过错（动机不正、获利有限、债权方自甘风险）承担补充赔偿，截留10万通道费返还。
- **结果**: 突破单一合同相对性整体考量，责任精确到人。

### 案例 2: (2013)民提字第90号（购房协议书）
- **问题**: 协议名为预约（还要签正式合同），已交定金并交房，什么关系？
- **使用**: 检验点4——履行行为探明真实意思：预约阶段不应交房，交房=本约意思。
- **结论**: 认定房屋买卖（本约）法律关系成立。
- **结果**: "预约还是本约不能只看一份孤立协议"成为标准表述。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？
1. 审查大宗商品购销/供应链合同，怀疑无实货的融资安排
2. 客户被追加为通道方/仓储方被告，要定责任
3. 借款合同里夹着顾问费、服务费、强制保险，要算真实本金利率
4. 交易文件是意向书/认购书/订购书，争"到底有没有合同、是预约还是本约"
5. 写起诉状需要选择正确案由与请求权基础

### 语言信号
- "走账""过桥""通道""闭环""循环贸易""融资性贸易""空转"
- "砍头息""变相利息""服务费 抵扣 本金"
- "预约还是本约""认购书 效力""意向书 算不算合同"

### 与相邻 skill 的区分
- 与 `ms2-atypical-security-identify`：还原后承认担保功能、继续按担保处理的（让与担保等）归那边；本 skill 覆盖还原为借贷、拆解虚伪结构、变相利息、预约本约等更广谱的定性场景。
- 与 `ms2-contract-validity-layers`：本 skill 只解决"是什么"（146条虚伪表示的识别）；"无效之后效力如何、隐藏行为是否也无效"转那边。
- 与 `ms2-contract-trial-five-steps`：本 skill 是五步法第一步"定性质"的专项工具。

## E — 可执行步骤 (Execution)

1. **绘制资金流与货物流流向图**
   - 完成标准：闭环/开环、有无实物交付一目了然；标注时间线（同日签约、价差、回购）。
2. **跑四检验点**
   - 完成标准：主合同存在性/真实交付/对价合理性/履行行为逐项留证。
3. **形成定性结论**
   - 完成标准：明确真实法律关系（借贷/担保/本约/预约/虚伪通道），并指出虚伪表示与隐藏行为两层。
4. **分配层次后果**
   - 完成标准：伪装行为效力、隐藏行为效力（转效力分层 skill 深审）、各方责任（借款人清偿、通道方按原因力+过错补充、仓储方无实货交付则免责、预扣息冲本）。
5. **校准请求权基础与案由**
   - 完成标准：诉请与还原后的法律关系一致（避免"按买卖要货款"式错位）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 有真实货物与市场风险承担的正常连环贸易——外观优先，不轻易穿透。
- 当事人就是想做担保安排并已公示——转 ms2-atypical-security-identify 承认其担保效力。

### 作者在书中警告的失败模式
- 循环贸易虚增业绩→背俗无效+系统风险（ce11）；参与方"试法行为"不受司法保护（招财宝案思路）。
- 把承诺书/还款协议与催款通知书混同（预约场景：把履行手续的格式合同当本约）。

### 作者的盲点 / 时代局限
- 书中多处定性争议作者自认"仍在研究中"（如无真实融物的融资租赁中租金条款如何转化、出借人无资质时定性）——输出此类结论须标注不确定性。
- "何时应尊重交易形式（外观主义边界）"讨论较少，穿透勿过度。

### 容易混淆的邻近方法论
- 虚伪表示（146条，双方通谋）vs 欺诈（148条，单方被诱）——还原时先分清，效果不同（无效 vs 可撤销）。
