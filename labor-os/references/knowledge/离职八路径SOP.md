## 路径01 协商解除

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P12
- 依据: 《劳动合同法》第三十六条 + 第四十六条
- verified: pending

**法定条件**:双方**协商一致**;用人单位提出 → 需支付经济补偿(N)。
**SOP**:
1. 初步沟通,确认协商意愿;
2. 协商补偿方案(标准:N,可视情形上浮);
3. 起草《协商解除协议书》 — 必须包含:①解除合意;②补偿金额与支付时点;③离职手续与社保转移;④**保密与权利放弃兜底**(放弃诉讼/仲裁权利);
4. 现场签 + 现场付(避免后续争议);
5. 出具离职证明 + 办档案 + 社保减员。

**成本与风险**:
- 成本 = N(每满一年支付一个月工资);
- 风险等级 🟢 最低(双方合意);
- **风险点**:若协议未写"无其他争议"或"权利放弃",可能后续被追诉;补偿方案**低于法定N**且非劳动者真实意思表示的,可被认定显失公平撤销。

⚠️ 实务观点,非法律依据:实务中**补偿可高于N**(常见1.5N-2N);关键是与劳动者充分沟通,**不可胁迫**。

### 工具书增补(2026-09-03蒸馏)

- 权威层级: 案例库参考案例 + 司法解释
- 来源: 《手册》P270-272、P177
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

**① 补偿金支付不得附"离职后义务"条件(北京某贸易公司诉王某)**
- 裁判要旨:离职协议可约定补偿金附条件,但条件须以达成解除为目的、限于**解除前已发生事项**(办交接、归还物品等);以劳动者离职后履行保密、竞业限制义务作为拒付条件的,法院不予支持。
- 踩坑点:单位发现王某入职竞对即拒付补偿并称"其违约在先"——补偿金具补偿性、救济性,解除且协议目的达成后给付即确定;付款时点早于竞业期届满,以将来不确定的履约行为作付款条件"缺乏逻辑"。
- 反转边界:协议存在欺诈、胁迫、乘人之危的除外;离职后竞业违约应**另案追竞业违约金**(本案王某已被裁赔竞业违约金281168元),不得反扣补偿金。
- 互链:本条主条目在合同条款库(S-CA22);竞业期限口径见合同库竞业块(24个月上限保留,指导案例184号按实际支付补偿月数细化)。

**② 结算协议的撤销事由仅两种(解释(一)第35条)**
- 解除/终止结算协议:不违反强制性规定且无欺诈、胁迫、乘人之危的**有效**;可撤销事由仅**重大误解、显失公平**两种——签协议前是唯一低成本纠错窗口。
- 一揽子弃权条款("不得再主张权利""互不追究"):不违反强制性规定且无欺诈胁迫乘人之危的有效并作裁判依据(浙江解答(四)问五,主条目在合同条款库,此处参见)。

**③ 工龄合并(解释(一)第46条)**:劳动者非因本人原因从原单位被安排到新单位的,原单位工龄合并计算——影响各路径经济补偿/赔偿金年限;细则见路径06注释。

## 路径02 严重违纪解除

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P12 + 课件2 P39(制度合法性)
- 依据: 《劳动合同法》第三十九条第(二)项
- verified: pending

**法定条件**:
- 劳动者**严重违反用人单位的规章制度**;
- 该规章制度**经民主程序制定**并**向劳动者公示/告知**;
- 违纪行为**严重性**达到规章制度中"严重违反"的标准。

**SOP**:
1. 制度合法性自检(民主程序+公示证据);
2. 违纪事实调查(尽量书面证据/多份证据相互印证);
3. **事先告知工会**;听取工会意见;
4. **提前书面通知劳动者**(说明违纪事实+制度依据+解除决定);
5. 办离职手续(工资5日内结清,社保减员)。

**成本**:0(不需经济补偿);
**风险**:🟢低(制度合规前提下);
**核心风险**:制度本身被认定无效(无民主程序/未公示/规定过严超过合理限度)。

⚠️ 实务观点:**严重违纪的界定应量化**(处分梯度);否则易被认定规章制度无效。

**① 解除通知锁定审查范围(指导案例180号)** 原文:
> 人民法院在判断用人单位单方解除劳动合同行为的合法性时,应当以用人单位向劳动者发出的解除通知的内容为认定依据。……用人单位超出解除劳动合同通知中载明的依据及事由,另行提出劳动者……存在其他严重违反用人单位规章制度的情形……人民法院不予支持。

- 裁判要旨:解除合法性=通知所载事由;庭审另补事由一律不采纳(诚实信用+禁止突袭,"先解雇、后找理由"被封死)。
- 踩坑点:通知载"旷工3天以上",庭审另提未穿工服、代打卡、辱骂主管——不予采纳;就旷工事由仅举自制考勤表(无劳动者签字),停工后是否通知返岗举证不能→旷工事实不清→违法解除。
- 反转边界:通知同时载明多项事由且各项证据充分的,逐项审查;"通知前已掌握的违纪未写入通知=视为放弃以该事由解除"。
- 审查框架(四步):**锚定**(通知载明事由为唯一范围)→**时点**(以解除决定作出时的事实证据法律为标准)→**举证**(单位对通知事由负举证)→**排除**(庭上追加事由一律不予支持)。

**② 违纪解除的比例原则(北京某制药公司诉李某某)** 原文:
> 用人单位以劳动者违反规章制度为由解除劳动合同,应审查劳动者的行为是否严重违反公司规章制度……在规章制度设置了纪律处分类别的情况下,应判断劳动者的行为属于规章制度中的哪一具体情形及其行为后果,同时考量劳动者的工作岗位和职责要求,判定解除劳动合同的合法性。行为未达到应予解除的严重程度的,不能以此为由解除。

- 裁判要旨:行为定性须结合岗位职责**对号入座处分阶梯**——包装操作员"未如实记录废品数量"=违反标准操作流程,≠"篡改公司文件记录";后果未达"严重影响/损失"程度不得解除,GMP强合规行业亦然。
- 踩坑点:制度设"口头警告→书面警告→最后书面警告→解除"四级处分的,轻行为跳档适用解除=违反比例原则(本案单位付21万余)。
- 反转边界:触犯绝对禁区行为(刑事责任、性骚扰+调查中虚假陈述,见③)不经阶梯审查;制度未设阶梯的直接做行为定性与后果评估。
- 四步框架:**制度效力**(民主程序+公示)→**行为定性**(岗位职责+行业强制规范)→**后果评估**(严重性由单位举证)→**阶梯对应**(不得跳档)。

**③ 正面样本:管理责任型严重违纪(指导案例181号 霍尼韦尔)**
- 裁判要旨:管理人员未合理处置性骚扰投诉、撮合纵容、提议解雇受害者、调查中虚假陈述=未尽岗位职责严重违反规章制度,解除合法、不付赔偿金。
- 反转边界:以反性骚扰制度经民主程序+员工签收为前提;针对负有管理/监督职责人员;普通员工间纠纷不适用。

### 解除程序与事由红线(工具书+浙江口径,2026-09-03蒸馏)

- 权威层级: 司法解释 + 地方司法口径 + 部门复函 + 司法文件
- 来源: 《手册》P177、P198-199 + 《汇编》P620-622、P641、P137
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

- **工会程序补正(解释(一)第47条)**:解除符合39/40条但未按43条事先通知工会的,劳动者主张违法解除赔偿金应予支持——**但起诉前已补正有关程序的除外**。风险敞口仅到起诉前,"廉价保险":发生争议立即补通知。适用于路径02/04/05/06全部单方解除。
- **违纪解除权5个月除斥期间(浙江解答(二)问八,🟧浙江独有)**:用人单位一般应在知道或应当知道之日起**5个月内**行使解除权,逾期解除有被认定违法的风险;代理单位应及时处理违纪。
- **检察院相对不起诉≠"被依法追究刑事责任"(劳社厅函〔2003〕367号)**:相对不起诉(现刑诉法177条2款,引用用现行条文)不属于39条第(二)项情形,**不能据此即时解除**;行为本身构成严重违纪的仍可依其他情形解除;制度应单列"被不起诉但严重违纪"情形,否则解除依据落空。
- **学历欺诈解除"双排除"(意见(一)第19-21条)**:劳动者提供虚假学历证书等构成欺诈,单位据此解除的,劳动者主张经济补偿、赔偿金**均不支持**;"满一年未签书面合同视为已订无固定期限"→二倍工资封点11个月(学历陈述/二倍工资条款设计参见合同条款库)。
- **调岗与擅自离岗(浙江高院意见(试行)38-46条)**:调岗三要件(**不变更合同主要内容/生产经营所必需/劳动条件未作不利变更**)下劳动者有服从义务;擅自离岗连续超15日且制度无规定的,可按严重违反劳动纪律解除;限制30日预告解除权的违约金条款无效;服务期"培训费用"不含培训期间基本工资,"专业技术培训"不含上岗前和日常业务培训。🟥 该意见第40条"竞业未约定补偿=条款无效"旧口径已被解释(二)第13-14条+30%补差体系取代,不得再引用(现行口径参见合同条款库竞业块)。
- **旷工解除的边界参见**:工作地点约定不明时,拒绝不合理异地调岗≠旷工,据此解雇属违法解除(上海某品牌管理诉姚某案,主条目在合同条款库;反转边界:调动无不利影响且合理的除外)。

## 路径03 竞聘上岗

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P4-P6、P12
- 依据: 《劳动合同法》第三十五条 + 课件引最高法案例
- verified: pending

**法律本质**(P4):竞聘本质是用人单位向员工发出的**变更劳动合同的要约邀请**;员工参与并接受新岗位视为承诺,双方达成变更合意。

### 四条红线(课件4大雷区,P4):
1. 🟥程序合规性缺失 — 职代会程序瑕疵;
2. 🟥考核标准不公允 — 指标模糊/歧视性;
3. 🟥**"落聘即解雇"红线** — "未竞聘成功"=不胜任/严重违纪 → 单方解约 = **违法解除** → 需支付2N;
4. 🟥特殊群体保护缺位 — 三期/工伤/医疗期员工强制竞聘,侵犯特殊保护权益。

### 合规SOP(阶段一二三,P5-P6)

**阶段一 方案制定**:
- 成立专项工作组(HR+业务+工会+职工代表+外部劳动法专家);
- 制定详尽竞聘方案(岗位说明+量化考核规则);**"落聘≠解雇",提供转岗培训,设立特殊群体"竞聘豁免"**;
- 履行民主程序(送达职工代表 → 职代会审议 → 与工会平等协商 → 书面证据备案);
- 方案公示(不少于7个工作日) + 员工签收《竞聘方案告知确认书》。

**阶段二 组织实施**:
- 报名与资格审查 + 结果公示;
- 评审现场**全程录音录像存档**,评委组含**工会或职工代表**;
- 成绩双人复核 + 公示。

**阶段三 结果与合同变更**:
- 拟聘任名单公示期 ≥ 5个工作日 + 异议通道;
- **必须签《劳动合同变更协议书》**(新岗位、薪酬);
- 落聘安置:**优先内部转岗协商**;**协商不成**再进入待岗程序。

**关键合规句**(P5):"无书面变更协议或未协商一致,劳动合同仍按原约定履行。"

**成本**:0(无补偿)
**风险等级**:🟡中(若合规,风险可控)

⚠️ 实务观点:竞聘最容易踩"落聘即解雇"红线;实务案例中,劳动者一告一个准。

## 路径04 不能胜任工作解除

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P7-P8、P12
- 依据: 《劳动合同法》第四十条第(二)项
- verified: pending

### 正典依据:指导案例18号(末位淘汰)+ "军令状"案(工具书案例,2026-09-03蒸馏)

- 权威层级: 指导性案例 + 案例库参考案例
- 来源: 《手册》P258-259、P281-282
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

⚠️ 最高法指导案例18号(原课件P7结论的正典依据):**"末位淘汰"绝不等于"不能胜任"**,企业不能仅以排名靠后直接解除劳动关系。

原文(指导案例18号 中兴通讯(杭州)诉王鹏):
> 劳动者在用人单位等级考核中居于末位等次,不等同于"不能胜任工作",不符合单方解除劳动合同的法定条件,用人单位不能据此单方解除劳动合同。

- 裁判要旨:末位是相对排序,不胜任是绝对合格性判断,强制分布比例的末档≠不胜任。
- 踩坑点(反面警示):连续三次考核C2(末档占10%)即认定不能胜任;所谓"转岗"实为分销科解散所致平调,不构成"培训或调岗"法定前置 → 违法解除付2N。
- 反转边界:考核标准能证明劳动者**确不具备岗位胜任能力**(绝对标准而非相对排名)+已履行培训或调岗前置的,可依40条合法解除。

**"军令状"案(曹某诉苏州某通信)** 原文:
> 以解除劳动关系作为惩戒措施的"军令状"中,若约定的解除条件违反法律强制性规定的,应当认定约定无效。用人单位以"军令状"约定目标未完成为由主张依据约定解除劳动合同的,人民法院不予支持。

- 裁判要旨:业绩目标承诺本身有效(可作目标管理/绩效依据);"未达标自动离职/即行解除"条款因违反解除法定化而**无效**。
- 踩坑点:让销售签"完成率低于30%自动离职",业绩不达标径行终止——跳过"培训/调岗→仍不能胜任→40条"法定前置,判赔122641.83元;劳动者从未作出解除意思表示,不成立"自动离职"。
- 反转边界:单位确已履行培训或调岗程序、仍不能胜任的,可依40条合法解除;纯佣金/奖金与业绩挂钩的军令状不受此限。
- 前置审查框架(18号+军令状合并):**定性**(末位/限定比例≠不胜任)→**真实性**(转岗是否确因不胜任,排除部门解散等外因)→**前置程序**(培训/调岗必经)→**约定效力**(以解除为惩戒且违反强制性规定的部分无效)。

### 🟥法定四步闭环(缺一不可)

**步骤01 举证"初次不胜任"**:
- 明确、可量化的考核标准(经员工确认或公示);
- 通过客观数据/事实证明员工未达标。

**步骤02 履行"培训/调岗"程序**:
- **法定前置帮扶义务**;
- 培训:有针对性,保留记录;
- 调岗:合理的工作安排,薪酬待遇相当。

**步骤03 举证"再次不胜任"**:
- 经过培训或调岗后,再次考核;
- 证明员工**仍无法胜任新岗位或原岗位工作**。

**步骤04 履行法定解除程序**:
- 提前**30天书面通知**员工本人;
- 或**支付一个月工资**(代通知金,§N+1 中的 +1);
- **必须通知工会**,听取工会意见。

### 四大败诉"雷区"(P7)

1. 🟥不胜任举证不足 — 考核标准模糊/未确认/仅主观评价;
2. 🟥未履行帮扶程序 — 直接以"不胜任"解除或培训/调岗流于形式;
3. 🟥程序瑕疵:未通知工会 — **司法实践中最常见**的程序性违法点;
4. 🟥考核制度本身无效 — 未经过民主程序/未公示。

### 合规SOP(P8)

1. 夯实制度基础 — 经民主程序+公示的考核制度,留存签收记录;明确岗位说明书,**由员工签字确认**;
2. 首次考核认定 — 收集绩效考核表/业务数据,绩效面谈,**获取员工签字确认**;拒签的 EMS 邮寄或邮件送达;
3. 法定帮扶程序 — 专项培训并留存记录;调整至薪酬待遇相当、能力匹配的新岗位;
4. 二次考核与最终解除 — 帮扶期满后再考核;书面通知工会 + 征求意见;最后送达《解除通知书》说明解除理由+法律依据+经济补偿方案。

**成本**:N + 1(N = 经济补偿, +1 = 代通知金)
**风险等级**:🔴高(败诉率最高)
**周期**:中

⚠️ 实务观点,非法律依据:即便走完四步,**举证仍困难**,实务中败诉率高;**优先以协商解除替代**。

## 路径05 客观情况重大变化解除

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P9、P12
- 依据: 《劳动合同法》第四十条第(三)项
- verified: pending

### 三要件(P9)
1. 🟥严格界定"客观情况":**仅**政府征收、不可抗力、企业被兼并、企业亏损等"外部不可控因素";
   - 企业**主动的技术革新、业务调整、架构重组**等自主经营决策,**不属于**本项;
   - 但**各地口径不一,需要属地判断**。
2. 🟥核心实质:劳动合同**已"无法履行"** — 非简单工作内容调整,而是**原岗位被实质性撤销** + 用人单位无其他合适/可替代岗位。
3. 🟥不可逾越的红线:**诚信协商前置** — 即便符合前两项,也必须就调岗/调薪等变更事项**诚信、实质性协商**;只有充分协商仍**无法达成一致**时,方可依法解除。

**司法实践关键指引**(P9):
> 裁审对"客观情况重大变化"的认定秉持**严格审慎**态度,重点审查变化的"**客观性**"与"**不可归责性**",严防企业利用该条款规避经济补偿金支付义务。

**SOP**:
1. 收集外部不可控证据(如征收决定、不可抗力证明、企业被兼并公告、第三方审计亏损报告);
2. 证明原岗位实质性撤销,且无其他合适岗位;
3. **诚信协商**全部过程留痕(会议纪要 + 邮件 + 书面沟通);
4. 协商不成 → 提前30天书面通知 + 支付 N;
5. 通知工会。

**成本**:N
**风险等级**:🔴高(司法认定严苛)

⚠️ 实务观点:实务**慎用**;多数案例中,法院将"业务调整"认定为企业自主经营决策,**不构成客观情况变化**。

## 路径06 经济性裁员

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P10-P11、P12
- 依据: 《劳动合同法》第四十一条
- verified: pending

### 🟥法定人数门槛
**同时**满足:①裁减人员**20人以上**,**或**不足20人但**占企业职工总数10%以上**。

### 🟥法定触发情形(《劳动合同法》第四十一条)
1. **破产重整与生产困难** — 需第三方审计亏损报告等强力证据;
2. **经营调整与情势变更** — 转产、重大技术革新、经营方式调整,经变更合同后仍需裁员;或客观经济情况重大变化致合同无法履行。

### 🟥法定程序
1. **提前30日向工会或全体职工说明**实际生产经营状况;
2. 听取工会或职工的合理意见和建议,并进行研究答复;
3. **向当地劳动行政部门如实报告**裁减人员方案,接受行政监督。

### 合规SOP(P11)
1. **准备与内部决策**:
   - 收集财务审计报告、董事会决议等法定证据;
   - 制定裁员方案(被裁减人员名单 + 实施时间 + 经济补偿标准),**严格遵循"优先留用"法定原则**(与本单位订立较长期限固定期限、无固定期限、家有老幼等);
2. **履行法定民主程序**:
   - 提前30天召开职代会或全体职工大会;
   - 留会议通知、签到表、纪要及音视频记录;
   - 修改完善方案,回应职工合理意见;
3. **行政备案与正式实施**:
   - 报送当地人社部门备案,**取得备案回执**;
   - 送达《解除劳动合同通知书》、依法支付 N;
   - 出具离职证明、办理档案和社保转移。

**成本**:N
**风险等级**:🔴高(门槛最高 + 社会影响大 + 需人社备案)
**周期**:长(≥30天)

⚠️ 实务观点,非法律依据:经济性裁员是企业的**"最后选项"**,不当实施将面临补正通知、行政处罚甚至刑事责任。

### 关联:到期终止的"免补偿"抗辩(46条第5项,工具书案例,2026-09-03蒸馏)

- 权威层级: 案例库参考案例 + 地方司法口径
- 来源: 《手册》P273-275 + 《汇编》P651-652
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

原文(张某诉上海某国际货代):
> 劳动合同到期终止后,用人单位主张无须支付经济补偿金的,应就其以维持或者提高劳动合同约定的条件续订劳动合同而劳动者不同意续订承担举证责任。续订条件是否相对维持或提高的识别应以原合同终止前所达成的约定条件为基准。……

- 裁判要旨:46条第5项免补偿由**单位举证**;"维持或提高"以**原合同终止前实际达成的条件**为基准(含已争议未足额发放的岗位工资)。
- 踩坑点(降薪续签陷阱):同日发出"续签通知+取消岗位工资通知",劳动者回复"愿意续签但不同意取消工资"后合同到期——视为**降低条件续订**,拒签仍获补偿(判赔77000元)。
- 反转边界:续签通知明确维持或提高原条件、劳动者仍拒签的,确属"劳动者不同意续订",无须补偿;降薪确经协商一致或有充分合理性的除外。
- 浙江细化(解答(四)问八-十):"维持或提高"作**广义解释**,包括期限、岗位、地点等,约定工资与前合同相同即视为维持。

## 路径07 员工辞职

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P12
- 依据: 《劳动合同法》第三十七条
- verified: pending

**法定条件**:劳动者**提前30日以书面形式通知**用人单位(试用期内提前**3日**通知)。
**成本**:0(用人单位无需补偿)
**风险等级**:🟢最低
**周期**:30日

⚠️ 实务观点:实务中"被迫辞职"(用人单位存在过错)可主张经济补偿(《劳动合同法》第三十八条),常见情形:
- 未按约定提供劳动保护/条件;
- 未及时足额支付劳动报酬;
- 未依法缴纳社会保险费;
- 规章制度违反法律/损害劳动者权益;
- 因本法第二十六条第一款情形致合同无效;
- 法律、行政法规规定劳动者可解除的其他情形。

### 被迫解除(38条)程序红线(工具书+浙江口径,2026-09-03蒸馏)

- 权威层级: 地方司法口径 + 案例库参考案例
- 来源: 《汇编》P655-656、P646-647、P636-637 + 《手册》P297-298
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

三个高频败诉点(浙江):
1. **38条须先向单位提出**(解答(五)问八):未事先向用人单位提出,直接请求仲裁或法院裁判解除的,一般不予支持——被迫解除第一败点,置顶警示。
2. **辞职时未说明38条事由,事后翻用不支持**(解答(三)问七):辞职报告写"个人原因"后改口索补偿,不支持。
3. **解除前单位已补正的不支持**(解答(三)问六):劳动者提出解除前,单位已对未及时足额支付劳动报酬/未依法缴纳社保情形补正的,经济补偿不支持。⚠️ 与解释(二)第19条衔接:2025.09.01起"弃缴承诺无效"情形按新规一律支持补偿(单位补缴后可请求返还已付补偿),浙江旧口径仅适用于新旧分界前的案件;普通欠薪欠保的"四类豁免"(计算标准争议/经营困难合理理由/劳动者曾认可/缓缴经审批)仍有效。

其他规则:
- **解除通知不可单方撤销**(解答(五)问十):30日预告期届满前,提出解除的一方无权单方撤销——解除意思表示到达即生效。
- **不得以欠薪为由擅自离岗**(解答(三)问十一):该抗辩不成立,擅自离岗本身可构成违纪(连续超15日可解除,见路径02)。
- **40条解除未提前30日通知/未付代通知金=程序瑕疵**(解答(三)问九):补付代通知金即可,不构成违法解除、不付2N。
- **一次性支付竞业补偿后劳动者违约的,单位仍可主张违约金**(解答(一)问十);和解/调解协议数额过低不补差,除非胁迫欺诈或显失公平(问十三);违法解除继续履行支持与否以一审宣判时合同是否届满划界,工资损失按停发前12个月平均工资(问十二,与解释(二)17条衔接见路径08)。
- **未签书面合同不能作38条解除理由**(解答(二)问十):以未签合同为由解除并索补偿,不支持。

### 🟥警示:谁最后发出解除意思,谁担责(离职声明自认)

- 权威层级: 案例库参考案例
- 来源: 《手册》P297-298(曾某诉某网络科技公司)
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

原文:
> 在某网络科技公司并未向曾某送达解除劳动合同通知书的情况下,曾某提出解除劳动合同的仲裁请求并向某网络科技公司发送离职声明,应认定双方之间的劳动合同最终由曾某提出解除。

- 踩坑点:单位口头施压"不能胜任",补偿谈不拢,劳动者自行发邮件"离职声明"+仲裁请求解除→被认定**主动辞职**;38条事由不成立→无补偿;绩效型"年底三薪"系数0→年终奖同失(年终奖规则参见劳动报酬与补偿争议规则库;Z1与指导案例183号的张力已在浙江库互链处理)。
- 反转边界:有证据证明单位已明确作出解除意思表示(录音+解除通知送达),或辞职系因38条法定事由且事由成立的,可获补偿。
- 实务口径:员工勿在谈判中先行书面提出解除;单位勿以口头施压代替书面通知——**书面形态决定解除的归责**。

### 关联:竞业限制的离职启动管理(合规指引离职部分,2026-09-03蒸馏)

- 权威层级: 部门指导性文件(人社部办公厅2025.09.04)+ 地方司法口径
- 来源: 《汇编》P720-721、P651-652
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

- **离职启动评估**:入职时签了竞业协议≠离职必须启动;离职时按岗位、工作内容变化评估。**不启动的,在离职证明中注明或以其他书面形式告知劳动者**(书面化免责是关键动作)。
- **单位在离职时解除竞业协议,免付3个月额外补偿**(浙江解答(四)问六;与"因单位原因未付补偿致劳动者解除"情形区分,后者劳动者可解除约定并主张3个月补偿)。
- **支付纪律**:竞业期限内以货币按月支付,不得以"工资奖金已含补偿"抵充;迟付超1个月经劳动者提醒仍不付、或超3个月未付→劳动者可不再履行竞业义务。
- **期限口径(冲突决议落实)**:期限保留《劳动合同法》第24条**两年法定上限**;"仲裁诉讼期间不计入竞业期限"条款无效(指导案例184号),期限按**实际支付补偿金的月数**确定——184号系对24个月上限的细化而非突破。补偿未约定/过低≠条款无效,按前12个月平均工资30%补差(低于最低工资按最低工资)。
- 参见:竞业限制条款设计(人员过滤、范围/地域、违约金5倍参照)归合同条款库;竞争关系四维审查、隐蔽竞业穿透规则亦见合同库。

## 路径08 违法解除

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P13
- 依据: 《劳动合同法》第八十七条
- verified: pending

⚠️ "违法解除"不是合法路径,是其他路径**未合规实施**导致的**最重后果**。

**后果**:用人单位**违反本法规定解除或者终止劳动合同**的,应当依照第四十七条规定的经济补偿标准的**二倍**向劳动者支付**赔偿金**,即**2N**。

### 典型违法情形(贯穿上述六路径)
- 🟥不胜任但未培训/未调岗,直接解除;
- 🟥客观情况变化但未诚信协商,直接解除;
- 🟥未通知工会解除;
- 🟥竞聘落聘直接=严重违纪解除;
- 🟥严重违纪认定无证据或制度无效;
- 🟥经济裁员未达人数门槛或程序瑕疵;
- 🟥女职工"三期"期间无正当理由解除;
- 🟥工伤、医疗期员工解除;
- 🟥员工依法辞职,用人单位拒绝办理离职手续。

### 法律前沿新风险(2025-2026,P13)
- **司法解释(二)**(2025.09施行):细化"连续订立二次固定期限合同"的认定标准,严格限制用人单位利用合同期限规避义务、单方终止合同的行为;
- **浙江省解答(七)**(2025.12发布):续订最终选择权完全归属劳动者;用人单位不得利用优势地位,通过合同期限设置、岗位调整等方式规避法定义务,否则将承担**支付赔偿金**的法律后果。

### 工具书增补:赔偿金计算与恢复攻防(2026-09-03蒸馏)

- 权威层级: 案例库参考案例 + 司法解释
- 来源: 《手册》P291-294、P299-301 + 《汇编》P599-600
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

| 违法解除**赔偿金(2N)自入职之日起连续计算,不分段** | 杨某某诉重庆某公司,《手册》P291-292 | 87条赔偿金不分段;97条第3款分段规则仅适用于46条经济补偿;"节约成本裁员"不符合法定解除事由,未通知工会亦属程序违法;"工伤九级不能胜任"抗辩不成立 |
| **经济补偿跨法分段**(2008.1.1前段按当时规定) | 唐某诉重庆某工业,《手册》P293-294 | 2008前段按劳动法91条+劳部发309号支付;拖欠报酬被迫解除自入职起算;试用期解除例外;关联公司安排调动、合同约定工龄连续计入新单位 |

⚠️ 两案必须成对引用:赔偿金"不分段"结论**不得**误用到经济补偿场景,反之亦然。

**医疗期内违法解除:三项待遇并行(杨某诉某科技公司,广东高院抗诉再审)**
- 裁判要旨:违法解除赔偿金(惩罚性)+医疗期内病假工资(保护性给付)+医疗补助费(社会责任)性质不同,**一并支持**;医疗期按工龄核定9个月。
- 附加:未办职工医保的,单位补足与新农合报销的差额损失;"自离"认定被请假短信证据推翻。
- 反转边界:已依法参保缴费的不适用医保差额项;医疗期档位与解除分流规则见工时休假规则表(互链)。

**恢复劳动关系攻防(解释(二)第16-18条,"劳动合同已经不能继续履行"六情形)**
- 六情形封死强求恢复路径:①仲裁/诉讼期间合同期满且不存在应续订续延情形;②劳动者开始依法享受基本养老保险待遇;③单位被宣告破产;④单位解散(合并分立除外);⑤劳动者已与其他单位建立劳动关系(严重影响工作);⑥法律行政法规规定的其他情形。
- **职业病例外**:未做离岗前职业健康检查即解除接触职业病危害作业劳动者的,劳动者请求继续履行应支持(庭前已检查且无职业病或明确拒检的除外)——与"特殊保护群体的禁用路径"节互链。
- **期间工资**:违法解除后至继续履行前一日的工资损失,按正常劳动工资标准支付;双方均有过错的各自担责。
- 参见:解除决定由用人单位负举证责任,举证不能认定违法解除(指导案例179号,主条目在合同条款库)。

## 八路径横向对比(P12)

| 路径 | 适用场景 | 关键优势 | 关键风险 | 核心要点 |
|------|---------|---------|---------|---------|
| 协商解除 | 双方意愿均松动 | 成本可控,周期短 | 协议表达不当致后诉 | 协议须含权利放弃兜底 |
| 严重违纪 | 员工严重违规 | 成本=0 | 制度无效→违法解除 | 制度合法+证据充分 |
| 竞聘上岗 | 内部人才结构优化 | 成本=0,风险中等可控 | "落聘即解雇"红线 | 程序合规+落聘转岗 |
| 不能胜任 | 能力与岗位持续不匹配 | — | 法律门槛极高,败诉风险大,成本N+1 | 考核量化,培训/调岗前置必要 |
| 客观情况 | 外部不可抗力/重大情势致岗位灭失 | — | 司法认定严苛 | 必须经过"诚信协商变更"必经步骤 |
| 经济裁员 | 破产重整或生产经营严重困难 | — | 门槛最高,需人社备案 | 满足人数,严格履行民主程序 |
| 员工辞职 | 员工主动 | 成本=0 | "被迫辞职"反向主张补偿 | 书面通知+30日 |
| 违法解除 | (他人结果) | — | 成本=2N | 任何路径合规失败的最重后果 |

### 策略选择建议(P12)
- **优先内部优化** → 竞聘上岗(成本最低,首选);
- **慎用单方解除** → 不胜任/客观情况举证责任重,败诉率高;
- **协商一致为上策** → 无法定单方解除条件时,协商更灵活、风险低;
- **裁员为最后手段** → 仅应作为企业面临生存危机时的最后选择。

## 特殊保护群体的禁用路径

- 权威层级: 法律
- 属地: national
- 来源: 课件3 P4(竞聘保护)+ P13(法律前沿)
- 依据: 《劳动合同法》第四十二条 + 《女职工劳动保护特别规定》
- verified: pending

| 群体 | 禁用路径 |
|------|---------|
| "三期"女职工(孕期/产期/哺乳期) | 经济裁员、客观情况变化、不胜任、严重违纪(除非该员工同时符合) |
| 工伤职工(医疗期/停工留薪期) | 经济裁员、客观情况变化(医疗期内的) |
| 职业病诊断/观察期 | 客观情况变化 |
| 在规定的医疗期内的员工 | 不胜任 + 经济裁员 + 客观情况变化(除非该员工严重违纪) |
| 患病或非因工负伤,在规定的医疗期内的员工 | 同上 |
| 本单位连续工作满15年,且距法定退休年龄不足5年的员工 | 经济裁员 |
| 从事接触职业病危害作业的劳动者未进行离岗前职业健康检查的 | 客观情况变化 |

⚠️ 实务观点:违反特殊保护解除的,即使劳动者本人存在一定违纪行为,实务中**仍倾向于认定违法解除**(兼顾劳动者弱势地位)。

### 职业病岗位解除/终止的强制前置(工具书案例群,2026-09-03蒸馏)

- 权威层级: 案例库参考案例
- 来源: 《手册》P275-280
- verified: V1锚点核验通过 2026-09-03(工具书蒸馏)

**上表扩列**:"从事接触职业病危害作业未进行离岗前职业健康检查"一行,禁用路径不止"客观情况变化"——**协商解除(协议无效)与到期终止(违法终止)同样受限**:

| 情形 | 后果 |
|------|------|
| 未离岗职检即**协商解除** | 解除协议无效,劳动关系存续至职业病鉴定结论出具 |
| 未离岗职检即**到期终止** | 违法终止;签收退工单+领补偿款不能洗白 |
| 鉴定为**五级/六级**伤残 | 合同终止以**本人意愿**为准,单位不得到期径行终止 |
| 鉴定结论出具后 | 到期合同可依《工伤保险条例》终止并支付两项补助金(七级案) |

**案例① 未检先解(张某诉某劳务服务公司)** 原文:
> 用人单位安排从事接触职业病危害的作业的劳动者进行离岗职业健康检查是其法定义务,劳动者未明确已经知晓并放弃离岗前职业健康检查的权利的,该项义务并不因劳动者与用人单位协商一致解除劳动合同而免除。……在劳动者职业病鉴定意见未作出之前,双方的劳动关系并不因协议解除或者劳动合同到期终止。

- 踩坑点:派遣电焊工签协商解除协议并领补偿款,单位承诺"签后安排体检"次日反悔;3个月后确诊尘肺一期、七级伤残→判令**恢复劳动关系至鉴定结论出具之日**。
- 反转边界:协议明确载明劳动者"已知晓并放弃"离岗职检权利,且体检确已安排或劳动者明确拒绝检查的,协议可有效。

**案例② 鉴定期间终止+恢复(陆某诉某轧钢公司)**
- 踩坑点:涂漆工病休期间合同到期,未安排职检即终止;两年后确诊苯致白血病、六级伤残——单位三连败:①未做离岗职检不得终止;②签收退工单、领补偿款不改变违法终止性质;③为生计短暂他处打零工不阻断恢复劳动关系;判恢复并按最低工资标准补付期间工资。
- 反转边界:已依法完成离岗检查且职工本人提出终止的不适用;职业病认定结论出具、妨碍情形消失后单位无续订意思的,可于鉴定结论出具日合法终止。

**三期保护与85条前置(浙江解答(四)问六/八-十,2026-09-03蒸馏)**

- 来源: 《汇编》P651-652 | verified: V1锚点核验通过 2026-09-03(工具书蒸馏)
- 孕期女职工被40条解除:要求**恢复劳动关系**应支持;改要赔偿金的,须举证解除前已告知怀孕。
- 85条加付赔偿金以"**劳动行政部门责令限期支付而逾期不付**"为前置,未经前置不支持(与解释(二)联动)。
- 竞业解除权与续订广义口径见路径06/路径07互链。
