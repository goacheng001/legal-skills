# ADR 0006:引入 cangjie 审判方法论库与辩点创意模块

> 状态:已通过(v3.4,2026-09-08)
> 决策背景:2026-09-08 完成的《刑事审判实务》上下册仓颉蒸馏产出 28 个审判方法论 skill(达尔文独立盲测 165/168=98.2%)。用户决定统一取用,按"第一性原理+奥卡姆剃刀"完成本次融合;方法论源头为 khazix-creativity 六路径(种子记录/三约束/烂原型/跨界偷/空白30分钟/内在动机)。

## 一、背景

本 OS v3.3 的方法论底座是 crime-elements 要件库(5 份)与 cross-disciplinary 跨专业知识库(3 份),存在两类缺口:

1. **方法论缺口**:疑罪从无操作、量刑三步法、死刑过滤、证据三层审查、排非流程等审判一线方法论无处挂靠,阅卷/量刑/庭审三个高危节点靠模型通用知识兜底;
2. **生成缺口**:辩点矩阵收集"已发现"的辩点,缺少"从无到有"的发散算子;归档复盘只沉淀经验卡,不沉淀"难受点"规律。

## 二、决策

1. **方法论接入(改动B)**:28 个 cangjie skill 以 SKILL.md+test-prompts.json 双件复制入 `references/cangjie-skills/`;新增 `references/skill-map.md` 作唯一路由表,按四类节点组织(审查起诉 5/一审量刑 6/庭审 6/罪名专项 11),**每个 skill 附"辩护转化提示"**(审判视角→辩护视角换算,防法院方法论误用于辩护立场);调度表挂 3 处钩子;罪名专项并入 5 份 crime-elements 尾部索引。
2. **辩点创意模块(改动A)**:新增 `references/defense-creativity.md`(六路径跨界改写,composes-with khazix-creativity);`criminal-defense-strategy` 新增**可选**工具 1.5(辩点发散),产物经"待核实线索"附表与 disposition_list 律师确认;归档清单新增"难受点种子 3 条"字段,回流 case-experience-card。
3. **单一活跃版本**:cangjie-skills/ 为唯一活跃版本;移动硬盘蒸馏区只读封存,禁止双头修改。

## 三、关键约束(防膨胀与防串扰)

- **限载铁律**:每节点最多加载 2–3 个 skill,禁止全量注入(skill-map.md 写死);
- **不独立注册**:28 包不进全局 skills 目录、不注册触发词,只经本 OS 被动引用,规避触发串扰;
- **菜单不变**:16 项服务菜单、确认机制红线、Hard Fail 清单一概不动;发散产物永不自动进入文书;
- **可回滚**:改动均为增量文件+少量指针行,基线 3a207443 之后按 A/B/ADR 独立提交,可逐段 revert。

## 四、后果

- 正面:三高危节点获得盲测 98.2% 的方法论支撑;辩点生成获得结构化发散算子;归档复盘形成"难受点→规律→检查项"的自我改进闭环。
- 风险与对策:上下文膨胀→限载铁律;双源失同步→单一活跃版本声明;审判/辩护视角错位→辩护转化提示列;牵强类比→元典 MCP 核验+disposition_list 确认。
- 回归资产:各 skill 目录 test-prompts.json(盲测基线)保留于本库,供后续 darwin 复测。
