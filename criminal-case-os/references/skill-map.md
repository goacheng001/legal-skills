# cangjie-skills 方法论路由表（skill-map）

> **用途**：28 个审判方法论 skill 按办案阶段路由。这些 skill **不独立注册触发**（不在全局 skills 目录），只经本表被 OS 各节点按需引用。
> **⚠️ 限载铁律**：**每个节点最多加载 2–3 个 skill，禁止全量注入**——按当前案件争点就近选取，宁缺勿滥。同节点同时命中第四节（罪名专项）与第一～三节（阶段方法论）时，两处**合计 ≤3**；同争点冲突时**罪名专项优先**。
> **路由决策序**：① 按状态头〔罪名〕查第四节 → ② 按当前阶段节点查第一～三节 → ③ 合计受限载约束。
> 🔴 禁止把审判视角检查项直接当辩方动作执行——必须先经各行"辩护转化提示"换算。🛑
> **视角换算（必读）**：以下方法论蒸馏自**审判教材（法院视角"怎么审"）**。辩护使用时按各行"辩护转化提示"反向取用：法官的入罪检查项 = 辩方的风险预判清单；法官的出罪门槛 = 辩方的攻击目标。

## 一、审查起诉节点（调度至 `criminal-case-review` / `criminal-non-prosecution` 时选用）

| skill | 内容 | 辩护转化提示 | 选用场景 |
|---|---|---|---|
| `interpretation-scope-check` | 文义射程+兜底条款同类解释、类推禁止 | 法官用以控制入罪解释；辩方用它**攻击控方扩张解释**——凡起诉书依赖"其他方法"等兜底条款，先过文义射程检验 | 兜底条款、新型手段定性 |
| `regulatory-crime-review` | 行政犯三步审查（行政违法性→刑事违法性→实质出罪） | 法官的出罪门槛即辩方的论证路径：前置法不违法→刑事违法性失据；"国家规定"范围与地方规章效力是主攻点 | 涉枪涉药涉税非法经营等法定犯 |
| `in-dubio-pro-reo-review` | 疑罪从无：定罪存疑从无/量刑存疑就低/取证穷尽 | 反向预判法官何时敢判无罪（门槛一事实存疑、门槛二取证穷尽、结论不唯一），把证据链撕到"结论不唯一"即可触发 | 证据接近但未达证明标准 |
| `tax-crime-boundary` | 虚开目的限缩+逃税初犯免责 | 无骗抵税款目的→虚开出罪；初犯补缴+行政处罚→不予追究，**程序时限（立案前）是生死线**，须第一时间算日期 | 虚开增值税发票、逃税 |
| `fraud-intent-review` | 诈骗非法占有目的推定与反证 | 法官看"预警信号"清单定目的；辩方逐条给反证（有履约行为/资金用于经营活动/事后态度）即可瓦解推定 | 合同诈骗与民事纠纷界分 |

## 二、一审量刑节点（调度至 `criminal-sentencing-defense` 时选用）

| skill | 内容 | 辩护转化提示 | 选用场景 |
|---|---|---|---|
| `three-step-sentencing` | 量刑三步法（基准刑→情节调节→宣告刑） | 法官的计算表=辩方的复核表：逐格核对调节比例、**禁止重复评价**（自首已吸收当庭认罪、累犯已吸收前科的不得再评）是净增益点 | 一切量刑辩护的骨架 |
| `leniency-severity-calibration` | 宽严相济政策落法 | 政策语转译为具体从宽幅度主张；"宽"的一侧（初犯/偶犯/退赔谅解）对应可争取的量化情节 | 量刑情节组织与排序 |
| `death-penalty-filter` | 死刑三重过滤（证据/罪责/政策） | 法官的过滤逻辑=辩方的保命路线图：证据存疑→罪责排序（共犯中非最严重者）→政策（民间矛盾/被害人过错/赔偿谅解），逐层布防 | 可能判处死刑案件 |
| `surrender-merit-verification` | 自首立功核查（含送亲归案、规劝型） | 法官从严把握处即辩方易失分处：亲友捆绑送人不算自首、笼统投案不算——会见与笔录阶段就要按此取证固定 | 自首立功认定争议 |
| `statutory-timepoint-rules` | 时效/追诉期限/累犯5年/数罪并罚折抵等时点 | 时点规则是**硬性程序利益**：追诉时效经过→径行无罪；管辖/并罚时点算错即程序违法上诉点 | 时效、累犯、并罚折抵 |
| `drug-quantity-death-review` | 毒品数量与死刑限制（含量、纯度、净额） | 数量认定每降一档即远离死刑：查获物未含量鉴定不应计入死刑数量、液体/混合物折算规则是辩点 | 毒品重案 |

## 三、庭审节点（调度至 `criminal-trial-examination` / 认罪认罚程序时选用）

| skill | 内容 | 辩护转化提示 | 选用场景 |
|---|---|---|---|
| `courtroom-substantiation` | 庭审实质化：庭前会议、证人出庭、举证质证方式 | 法官的排期与出庭决定权=辩方的申请素材：死刑上诉应当开庭、关键证人"有异议必须出庭"是硬抓手 | 庭前会议、出庭申请 |
| `criminal-evidence-review` | 八类证据三层审查（能力→效力→证明力） | 法官的审查清单=辩方的质证清单：每类证据的瑕疵点（签名缺失/来源不明/笔录代签）即质证意见的骨架 | 阅卷后证据分析、质证提纲 |
| `illegal-evidence-exclusion` | 排非全流程（线索→审查→录音录像调取） | 排非启动门槛"线索+材料"清单反向指导会见取证：首次会见即固定疲劳审讯/笔录不符细节，才有立案可能 | 供述合法性争议 |
| `plea-lenient-review` | 认罪认罚具结审查（自愿性/量刑建议审查） | 法官审查自愿性=辩方防范"被认罪"：具结前核实认知/辩护人在场；量刑建议"明显不当"的抗辩点（孤立量刑/漏情节） | 认罪认罚案件全流程 |
| `speedy-trial-gatekeeping` | 速裁程序闸门（适用条件与程序转换） | 速裁不适用=辩方的程序权利：当事人对事实有异议/可能无罪辩点→应转普通程序，防"速裁快刀" | 速裁/简易程序选择 |
| `criminal-procedure-review` | 审级程序与涉案财物处置（含拒执衔接） | 程序违法点（管辖/超期/送达）+涉案财物权属（案外人异议、家属财产）双轨审查，后者是财产辩护的主战场 | 程序性辩护、涉财辩护 |

## 四、罪名专项路由（按状态头"罪名"就近选用；同时并入 crime-elements 索引）

| skill | 覆盖罪名/争点 | 辩护转化提示 |
|---|---|---|
| `self-defense-review` | 正当防卫五步（进行中/限度/行凶/互殴界分） | 五步中每步都是辩方出罪点："现实紧迫危险"起算、反对唯结果论、防范性备械不阻却防卫 |
| `joint-crime-culpability` | 共犯责任划分、实行过限、共犯中止 | 过限部分他人担责=为从犯切割；中止须"有效制止"——辩方要证明己方当事人仅消极退出之外另有阻断 |
| `traffic-escape-review` | 交通肇事入罪情形、逃逸双重身份、"因逃逸致人死亡" | 逃逸不得重复评价（入罪后不能再作量刑从重）；事故认定书可做刑事实质审查攻破 | 
| `illegal-fundraising-review` | 非吸四要件+集资诈骗目的界分 | "特定对象"人数突破与目的推定是两个出罪口：资金用于生产经营+全额退赔反证非法占有目的 |
| `rights-assertion-extortion` | 维权型敲诈勒索罪与非罪 | 权利基础+手段相当性双要件：正当索赔数额争议不构成敲诈——预设"维权≠敲诈"的辩护框架 |
| `ecommerce-smuggling-review` | 跨境电商刷单/推单伪报、税款流失 | 推单型主观明知弱+综合税制下税款流失计算存疑，是低税额出罪双支点 |
| `telecom-fraud-review` | 电诈集团成员责任梯度、境外园区 | 按"参与度+获利+层级"切割主从犯；境外案件证据链（境外取证合法性）常是硬伤点 |
| `two-cards-crime-line-drawing` | 帮信/掩隐/诈骗共犯三罪界分、"明知"推定 | 界分即降档：掩隐重于帮信、共犯重于帮信；明知推定六情形逐条反证（异常对价/专门工具/逃避监管的合理解释） |
| `organized-crime-review` | 黑社会四特征、恶势力、套路贷、涉财"高度可能性"没收 | 四特征逐项攻击（尤其危害性特征）；涉财没收的"高度可能性"举证责任在公诉方，案外人财产另案救济 |
| `drug-crime-review` | 毒品定性（贩卖/运输/持有/代购居间） | 代购蹭吸≠贩卖加价；"数量达标≠入罪"（卡未进入犯罪环节同理适用于未交付情形） |
| `duty-crime-review` | 职务犯罪要件（受贿利用职务便利、行贿谋取不正当利益） | "职务便利关联性"与"不正当利益"要件从严审查；行贿人主动交代适用从宽特别条款 |

## 五、使用纪律

1. **限载**：单节点 ≤2–3 个，按争点就近选取；路由不确定时先读该 skill 的 description，不匹配即放弃。
2. **视角**：所有 skill 输出是审判方法论，最终须经"辩护转化提示"换算并以 OS 灵魂原则（独立立场/不迎合）复核。
3. **时效**：时效提示散见个别 skill（如 tax-crime-boundary 注明以现行解释为准）；引用法条一律经元典 MCP 实时校验（与 OS 既有铁律一致），禁止凭记忆引用。
4. **回归**：各 skill 目录内 test-prompts.json（darwin 盲测 98.2% 基线）仅作维护资产，不随办案加载。
