# 解释界限审查：文义射程与兜底条款同类解释

## R — 原文 (Reading)

> "类推解释以法律无明文规定为前提……而扩张解释……对扩张解释的限制是不允许其超出法律规定用语可能的文义范围。"
>
> — 第一章第一节 罪刑法定原则

> "被兜底条款所涵摄的事项应当与所列举的事项具备同质性。"（第10章：非法经营罪第4项"没有明确规定的……未经最高人民法院答复，不得自行适用"）
>
> — 第一章第一节 / 第十章第四节

## I — 方法论骨架 (Interpretation)

罪刑法定的解释约束有一个可操作标尺：**文义射程**。对构成要件用语的解释，凡仍落在普通语用"可能的含义范围"内，属于允许的扩张解释；一旦超出射程、靠"行为与某罪相似"来定罪，就是被禁止的类推解释。法律有明文（哪怕是概括性规定）时根本不发生类推问题。对"其他……"型兜底条款，另有一道**同类解释**闸门：被涵摄事项必须与罪状明列事项在"社会危害性、刑事违法性、刑事处罚必要性"三性上相当。两道闸门的运用次序：先查文义射程（合法性），再做相当性比对（同质性），最后才谈处罚必要性。跳过前两步、直接以"违反前置法+有危害"入罪，就是兜底条款口袋化的典型路径。

## A1 — 书中的应用 (Past Application)

### 案例 1: 王力军无证收购玉米案（最高法指导案例97号）
- **问题**: 无粮食收购许可证收购玉米，能否落入非法经营罪第4项"其他严重扰乱市场秩序的非法经营行为"。
- **使用**: 将收购脱粒加工转卖行为与前三项（专营专卖物品/进出口许可/证券期货保险等）比对：未破坏粮食流通主渠道，三性不相当。
- **结果**: 不构成非法经营罪，再审改判无罪。

### 案例 2: 非法经营罪第4项的程序约束
- **问题**: 新业态行为能否径行适用第4项。
- **使用**: 教材明确：无规范性司法文件规定的，逐级请示最高法，未经答复不得自行适用。
- **结果**: 兜底条款适用被程序化收口。

## A2 — 触发场景 (Future Trigger) ★

1. 控方以兜底条款（非法经营、以危险方法危害公共安全、合同诈骗第5项等）起诉，需要审查解释合法性。
2. 对"明知""恶意""其他方法"等概括要件做扩大理解时，需要自检是否越界。
3. 新业态、新交易模式（虚拟货币、解债服务、跨境推单等）是否入罪的论证。
4. 起草裁判文书需要说明"为何不采纳某扩张解释"。

语言信号: "这样解释是不是类推""兜底条款能不能装得下""和前三项行为像不像""口袋罪""违反国家规定就能定吗"。

### 与相邻 skill 的区分（初稿，阶段3定稿）
- 与 `regulatory-crime-review` 的区别: 本 skill 管"解释是否越权"（文义与同质性）；后者管"前置法依据是否成立"（违法性次序）。

## E — 可执行步骤 (Execution)

1. **固定待检解释对象**: 写明对哪个条文的哪个用语作何理解（争议点表格化）。
   - 完成标准: 争议解释被表述为一个可判真假的命题。
2. **文义射程检验**: 以普通语用+专业语境确定用语可能的含义边界，判断待检事项是否在射程内。
   - 完成标准: 给出"射程内=扩张解释"或"射程外=类推"的明确判断及理由。
   - 判停: 射程外→不得入罪，转而出罪说理，不再做相当性分析。
3. **兜底条款相当性比对**（仅当涉及"其他"型条款）: 列出明列事项→提炼三性共同本质→逐项比对待评价行为。
   - 完成标准: 形成相当/不相当的比对结论；不相当即排除涵摄。
4. **程序合规检查**: 涉非法经营罪第4项或"违反国家规定"存疑的，核实是否经逐级请示、有无法院答复。
   - 完成标准: 有答复或完成请示记录，否则不自行适用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 民事/行政合同条款解释、立法目的探究等无入罪后果的场景。
- 罪状用语在射程内且无兜底条款——直接适用常规三段论即可。

### 书中警告的失败模式
- 仅凭"违反国家规定"推定符合兜底条款→口袋罪化（第一章；王力军案原审错误）。
- "其他"被理解成"一切"（同类解释缺位）。

### 作者盲点（阶段0批判）
- "文义射程""公众一般认知"的确定依赖法官语感，书未给出争议时的操作细则——实践应以最高法答复、指导案例为锚。

### 容易混淆的邻近方法论
- 类推≠当然解释；有利于被告的扩张（出罪方向）不受本框架限制。
