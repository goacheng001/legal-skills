# 宽严相济量刑落法

## R — 原文 (Reading)

> "既不能简单地将多个情节进行相互折抵，也不能任意地选择适用某个情节，而应当在全面考察犯罪的事实、性质、情节和对社会危害程度的基础上……总体从严，或者总体从宽。"
>
> — 第二章第四节 宽严相济的政策要求

> "单独的赔偿并不是酌定量刑情节，赔偿必须是出于真诚的认罪、悔罪，并取得被害方一定程度的谅解，才能作为酌定量刑情节。"（第二章第四节）

## I — 方法论骨架 (Interpretation)

政策落地的三件工具。工具一，**民间矛盾认定**：四要素（对象相对特定/危害相对有限/公众可理解/容忍度高）齐备才启动从宽考量，并排除不正当关系、非法债务、违法犯罪起因；认定后过 13 项考量清单（起因可否同情、被害人过错、有无预谋、手段、事后行为、是否迁怒无辜、救助与自首、悔罪、赔偿谅解、舆论、一贯表现、家庭情况等）定幅度。工具二，**逆向情节总体评价**：从宽与从严情节并存时禁止"你减一点我加一点"的折抵，先对全案做总体方向的定性判断（总体从严或总体从宽），再进入情节调节。工具三，**赔偿与区别对待**：赔偿+真诚悔罪+谅解三者合一才构成酌定从宽；罪行极重者不得以赔偿换从宽（防"花钱买刑"）；共同犯罪能分清主从的必须认定并在量刑上拉开差距，不能以"分不清"为由一律重判。

## A1 — 书中的应用 (Past Application)

### 案例 1: 复婚被拒杀人案的政策定性
- **问题**: 离婚后要求复婚遭拒而杀人，是否属婚姻家庭矛盾。
- **使用**: 矛盾因婚姻关系而起、动机明确、对象特定→一般视为婚姻家庭矛盾，进入 13 项考量。
- **结果**: 予以从宽考量的政策空间。

### 案例 2: "花钱买刑"防线
- **问题**: 罪行极重者以大额赔偿取得谅解求从宽。
- **使用**: 公然对抗社会、罪行极其严重的不得以赔偿谅解从宽；民间矛盾类才可依法从轻并控制幅度。
- **结果**: 刑事部分从严与民事赔偿并行。

## A2 — 触发场景 (Future Trigger) ★

1. 被告人同时有自首/从犯与累犯/前科等逆向情节，量刑有分歧。
2. 民间纠纷激化引发的伤害、杀人案，辩方主张"事出有因"从宽。
3. 被告方积极赔偿、被害方出具谅解书，从宽幅度争议。
4. 多被告人共同犯罪，量刑需要拉开档次。

语言信号: "该宽则宽""因民间矛盾引发""赔偿了也谅解了能从多少""累犯和自首怎么平衡""都判重的依据是什么"。

### 与相邻 skill 的区分（初稿）
- 与 `death-penalty-filter`: 本 skill 管一般案件的宽严方向与幅度；死刑案件再过那道更严的过滤。
- 与 `three-step-sentencing`: 那个管量化流程；本 skill 管方向与政策判断，二者先后衔接。

## E — 可执行步骤 (Execution)

1. **政策定位**: 判断案件是否属从严清单（严重治安/腐败/黑恶/涉众/毒品等）或从宽清单（民间矛盾/未成年人/轻罪）。
   - 完成标准: 宽严基调及依据记录在案。
2. **民间矛盾四要素检验**（如主张从宽）: 对象特定/危害有限/公众理解/容忍度逐项核对，再过排除清单。
   - 完成标准: 认定或排除民间矛盾并说明理由。
   - 判停: 不构成民间矛盾→从宽主张仅依其他法定情节处理。
3. **13 项考量打分**: 逐项列明对从宽的支撑与削弱，形成幅度倾向。
   - 完成标准: 清单齐备、幅度倾向可复述。
4. **逆向情节总体评价**: 先定总体方向，再进入具体调节（衔接 three-step-sentencing）。
   - 完成标准: 总体方向判断有说理。
5. **赔偿三分量**: 查赔偿真实性、悔罪、谅解的对应关系与数额合理性；防"花钱买刑"。
   - 完成标准: 赔偿情节的从宽分量有明确结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 宽不是法外开恩、严不是法外加重——任何从宽从严都必须有法定或酌定依据；政策不能替代构成要件判断。

### 书中警告的失败模式
- "非宽即严""轻罪宽、重罪严"的机械对应。
- 以分不清主次为由一律重判。
- 大额赔偿换取失衡从宽。

### 作者盲点
- "公众感受"标准弹性大，书中以"朴素正义观"兜底，需防情绪化量刑。

### 容易混淆的邻近方法论
- 酌定从宽≠法定从宽；调解重点限于民间矛盾类与当事人和解类，敏感案件不宜主动调解。
