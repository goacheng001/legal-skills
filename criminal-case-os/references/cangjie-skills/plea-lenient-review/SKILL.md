# 认罪认罚案件审查与量刑建议处理

## R — 原文 (Reading)

> "我国的认罪认罚从宽制度，不同于西方一些国家的辩诉交易。在我国，无论被告人是否认罪、无论判处刑罚轻重，作出有罪判决都要坚持证据裁判……认罪认罚案件的证明标准没有降低。"
>
> — 《刑事审判实务（下册）》第21章第一节

> "只有被告人认罪认罚的供述，没有其他证据的，或者事实不清，在案证据不能排除合理怀疑的案件，均应当坚持疑罪从无，依法宣告无罪，严守防范冤错案件、防止罪及无辜的底线。"
>
> — 同书第21章第一节

---

## I — 方法论骨架 (Interpretation)

认罪认罚案件法院审查的四道关：

1. **构成关**：认罪=认事（对主要犯罪事实无异议；性质辩解但接受认定意见不影响；仅表态/妨害司法的不算）；认罚=愿意接受刑罚+悔罪实质（退赔赔偿修复；转移财产有能力不赔的不算）。
2. **事实关**：证明标准不降低——只有认罪认罚供述无其他证据的不定罪；事实基础存疑转普通程序；防止"情节显著轻微"被凑成犯罪（高某案宣告无罪）。
3. **三性关**：自愿性（核心）×真实性（基础）×合法性（前提），庭审五查（暴力威胁引诱、认知精神状态、理解后果、告知义务、有效法律帮助与具结见证）。
4. **量刑关**：量刑建议"一般应当采纳"，五类应当不予采纳；"明显不当"五情形，幅度因罪名而异（危险驾驶差1-2个月即可认定，十年以上案件须差半年以上）；不调整或调整后仍不当→依法判决。从宽阶梯：认罪认罚≤30%，叠加自首等≤60%，轻罪可更高或免刑；早认罪优于晚认罪（二审幅度小于一审）；共同犯罪注意全案平衡。

## A1 — 书中的应用 (Past Application)

### 案例 1: 高某聚众斗殴案
- **问题**: 已签具结书、公诉建议缓刑。
- **方法论的使用**: 事实基础审查——高某仅站于5米外观看，非积极参加者。
- **结果**: 宣告无罪。

### 案例 2: 尚某某、薛某污染环境案
- **问题**: 公诉机关因辩护人提出取证瑕疵意见而撤回具结书、上调量刑建议。
- **方法论的使用**: 辩护权独立，辩护意见≠被告人反悔。
- **结果**: 法院不予支持，维持原建议。

### 案例 3: 某故意伤害案
- **问题**: 确定刑建议前未听取被害人意见，庭审暴露被告人转移财产。
- **方法论的使用**: 有能力不赔→不认定认罪认罚。
- **结果**: 量刑建议由二年调至二年四个月获采纳。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 审查认罪认罚案件是否可以按具结书判决、量刑建议要不要建议调整。
2. 被告人当庭/庭后/二审才认罪认罚，或签署后反悔、辩护人与被告人意见不一。
3. 评估从宽幅度（能否突破30%/60%、与自首等情节如何叠加）。

### 语言信号

- "量刑建议明显不当怎么办"
- "具结书签了还能反悔吗"
- "认罪认罚能减多少"
- "辩护人做无罪辩护还算认罪认罚吗"

### 与相邻 skill 的区分

- 与 `speedy-trial-gatekeeping` 的区别: 本 skill 管认罪认罚的实体与量刑审查；后者管"能否用速裁程序、如何转程序"。
- 与 `courtroom-substantiation` 的区别: 本 skill 是认罪认罚轨道的专属规则；普通程序量刑编排归后者。

## E — 可执行步骤 (Execution)

1. **过构成关**: 逐项核对认罪（认事）与认罚（悔罪实质）；存在妨害司法、有能力不履行的，不予认定。
   - 完成标准: 形成认罪/认罚成立与否的书面判断。
2. **过事实关与三性关**: 按证明标准独立审查关键证据；庭审五查核实三性。
   - 判停条件: 事实基础存疑或违背意愿→转普通程序重新审理。
3. **过量刑关**: 对照五类不予采纳情形与"明显不当"五情形→采纳/告知调整/依法判决；从宽幅度按阶梯与"四性"确定，注意阶段差异与共同犯罪平衡。
   - 完成标准: 判决对量刑建议采纳与否说明理由与依据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 案件不符合认罪认罚条件而当事人想"谈条件"（我国制度非辩诉交易，不能就事实讨价还价）。
- 仅程序选择问题（速裁/简易/普通）而不涉及认罪认罚审查。

### 作者在书中警告的失败模式

- "一刀切"从宽、量刑建议照单全收（ce44）。
- 因认罪降低证明标准、以具结书替代证据审查（ce45）。
- 把辩护人独立辩护意见当作反悔并报复性加刑（ce46）。
- 未听取被害方意见即出确定刑建议（转移财产案）。

### 作者的盲点 / 时代局限

- 指导意见正在修订中（书中自认），幅度规则可能调整；对值班律师实质帮助率的制度性短板未展开。

### 容易混淆的邻近方法论

- 认罪认罚≠自首坦白（可叠加评价但禁止重复评价）；速裁≠简易。
