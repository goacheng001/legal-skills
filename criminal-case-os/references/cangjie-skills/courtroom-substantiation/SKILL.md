# 庭审实质化操作

## R — 原文 (Reading)

> "为防止庭前会议架空或弱化庭审……要把握好庭前会议中证据开示的程度……又不应达到庭审质证程度，导致庭审虚化。一般不主张详细宣读证据内容……控辩双方在庭前会议中不质证、不辩论。"
>
> — 《刑事审判实务（下册）》第18章第二节

> "被告人及其辩护人参加量刑问题的调查的，不影响作无罪辩解或者辩护。"
>
> — 同书第18章第三节

---

## I — 方法论骨架 (Interpretation)

庭审实质化=四个操作模块：

1. **庭前会议（减负而非预演）**：四种情形可开（证据多案情复杂/社会影响重大/争议大/其他中断事项），排非申请+线索材料的必须开。五项内容：程序事项、证据展示（不质证不辩论）、排非审查、附带民调解、实体过滤（明显事实不清可建议撤诉）。合意与处理决定对庭审有拘束力——撤回的证据无新理由不得再出示，反悔须正当理由。
2. **证人出庭（三层保障）**：出庭范围=有异议+对定罪量刑有重大影响；保障梯度=协助到庭→视频作证→强制到庭（院长令，配偶父母子女除外）→补助与保护→训诫拘留。出庭后庭前证言一般不再出示（三种例外）。
3. **举证质证（一证一质为原则）**：关键证据、有争议证据单独举证质证；无争议非关键证据可简化但非免质；技侦证据须保护措施或庭外核实；庭外调查所得证据原则上经庭审质证（非关键/有利于被告人的量刑证据可庭外征求意见）。
4. **量刑程序（四轨道）**：速裁/简易/普通认罪/普通不认罪分别处理；不认罪案件先辩定罪、后辩量刑；参加量刑调查不作无罪辩护的自认；量刑建议按认罪认罚与否两分审查。

## A1 — 书中的应用 (Past Application)

### 案例 1: 高某聚众斗殴案（配合事实基础审查的庭审设计）
- **问题**: 被告人已签具结书、建议缓刑。
- **方法论的使用**: 仍对"是否积极参与"作实质调查。
- **结果**: 宣告无罪——庭审不因程序从简而虚化。

### 案例 2: 王某受贿案
- **问题**: 一次讯问无同步录音录像。
- **方法论的使用**: 庭审排非调查中审查录像完整性。
- **结果**: 该次笔录排除。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 制定重大复杂案件庭审方案（要不要开庭前会议、开几次、议什么）。
2. 处理证人出庭申请、证人拒不出庭、鉴定人出庭与专门知识的人辅助质证。
3. 安排示证质证节奏、处理庭审中程序争议（突然申请排非、证据突袭）。

- 与 `plea-lenient-review` 的区别: 认罪认罚案件的具结、量刑建议调整细节归后者；本 skill 管普通程序的庭审骨架与量刑程序模式。

## E — 可执行步骤 (Execution)

1. **庭前评估**: 是否存在四种启动情形→决定是否召开；确定议程（程序事项清单+证据展示程度+是否排非审查）。
   - 完成标准: 形成庭前会议提纲；明确"不质证不辩论"边界。
2. **出庭安排**: 逐个核对异议证人对定罪量刑的影响→通知出庭/视频作证/强制到庭递进；核实旁听人员中无证人鉴定人。
   - 完成标准: 出庭名单与保障措施确定。
3. **庭审组织**: 按一证一质原则排证据组；定罪证据在前量刑证据在后；不认罪案件分两段辩论；量刑建议按两分法审查。
   - 完成标准: 庭审提纲与质证方案就绪；判决书回应控辩重大争议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无争议简单案件滥开庭前会议（浪费资源、违背功能设定）。
- 以庭前证据展示取代庭审质证（导致庭审虚化）。

### 作者在书中警告的失败模式

- 庭前会议开成"预演庭审"（ce29）。
- 庭前合意随意反悔、撤回证据庭审"复活"（ce31）。
- 案卷证据取回由控辩一方带走（只能当庭借用、质证后归还）。

### 作者的盲点 / 时代局限

- 未讨论庭审直播、远程庭审常态化下的新程序问题；对辩方庭审资源不足着墨少。

### 容易混淆的邻近方法论

- 庭前会议≠庭前审查（后者是公诉案件程序性入口审查，归 criminal-procedure-review）。
