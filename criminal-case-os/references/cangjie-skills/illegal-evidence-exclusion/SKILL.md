# 非法证据排除全流程操作

## R — 原文 (Reading)

> "对隐匿身份人员向被引诱人提供毒品或者毒资、购毒渠道的案件，应采用排除非法证据的救济方法……排除上述证据后，在案证据达不到认定被引诱人有罪的证明标准的，应当依法作出证据不足、指控的犯罪不能成立的无罪判决。"
>
> — 《刑事审判实务（下册）》第16章第三节（排非救济的延伸适用）

> "不得以签名并加盖公章的说明材料替代侦查人员出庭。"
>
> — 同书第18章第二节

---

## I — 方法论骨架 (Interpretation)

排非是一条带闸门的流水线，八步走：

1. 辩方开庭前申请并完成**初步举证**——"线索"（人员、时间、地点、方式，内容具体指向明确）+"材料"（伤情照片、体检记录、病历、笔录、录像、同监室证言）。
2. 法院"守门员"审查：未提供线索材料→告知补充，不补不予受理；已提供→开庭前会议3日前送检察院；无疑问可驳回。
3. **庭前会议**审查：核实材料、针对性播放录像、通知侦查人员参加；控辩可撤回申请/证据（无新理由不得再提/再出示）。
4. 庭审**先行调查为原则**：合法性争议处理前，被申请排除的证据不得出示质证；调查中不得宣读供述内容（只解决证据能力）。
5. 证明责任在检察院：笔录、提讯登记、体检记录、文书、录像、侦查人员出庭说明；经通知不出庭且不能排除非法的，排除。
6. 认定标准：确认非法→排除；"现有证据不能排除非法"（应录像未提供、录像选择性录制剪接删改、不在规定场所讯问）→排除。
7. 原则当庭决定；排除后不得作为定案根据。
8. 二审三种情形：对一审结论有异议/一审未告知权利或新发现线索→二审可排除后维判或改判发回；一审未审查即采信→撤销原判发回。

认定标准分层：供述三情形（暴力变相肉刑、威胁达难以忍受精神痛苦、非法拘禁主导）；重复性供述一并排除＋两例外；证言陈述（暴力威胁非法限制人身自由）；实物证据裁量排除（补正优先）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 黄某东受贿案
- **问题**: 刑拘前传唤限制人身自由90小时、患病不给药、连续做7份笔录。
- **方法论的使用**: 判断非法限制人身自由是否占主导地位。
- **结果**: 有关供述排除。

### 案例 2: 黄某坚等贩卖运输毒品案
- **问题**: 二审发现讯问录像与笔录差异极大、疑似补录。
- **方法论的使用**: 录像不能证明取证合法性→"不能排除"→排除。
- **结果**: 排除供述，撤销原判发回重审。

### 案例 3: 杨某龙故意杀人案
- **问题**: 排除有罪供述后无补查可能。
- **方法论的使用**: 排非与疑罪从无衔接。
- **结果**: 依法宣告无罪。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 辩护人起草排非申请书，需要评估线索材料是否达标。
2. 法官助理/承办法官审查排非申请、组织庭前会议、撰写排非审查报告。
3. 二审对一审排非处理的上诉、抗诉争议。

### 语言信号

- "他说被刑讯逼供了怎么办"
- "没有同步录音录像的笔录能用吗"
- "排非申请怎么审查"
- "疲劳审讯怎么认定"

### 与相邻 skill 的区分

- 与 `criminal-evidence-review` 的区别: 本 skill 是"程序性救济通道"，只处理取证合法性；证据真实性、证明力问题归后者。
- 与 `courtroom-substantiation` 的区别: 庭前会议在本 skill 中仅作为排非审查场域；其会议组织、拘束力等一般规则归后者。

## E — 可执行步骤 (Execution)

1. **定性申请**: 判断排除对象（供述/证言/实物）与主张的非法方法。
   - 完成标准: 明确适用绝对排除还是裁量排除路径。
2. **核初步举证**: 对照线索+材料二分标准；不足→告知补充。
   - 判停条件: 辩方在核查询问时曾明确表示无非法取证的，要求说明理由，无疑问可驳回。
3. **走流程**: 庭前会议审查→（有疑问）庭审先行调查→检察院举证→录像四查（依法制作/完整/无剪接删改/与笔录无实质差异）→决定。
   - 完成标准: 形成排除或不排除的书面/当庭决定并说明理由。
4. **处理后果**: 排除后证据是否仍足认定；不足→无罪/改判/发回；一审未审查即采信的→撤销原判发回。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 仅主张"取证程序有小瑕疵"（无签名、时间笔误）——走补正通道，不是排非。
- 证人仅因 convenient 未出庭而要求"排除证言"——出庭问题归 courtroom-substantiation。

### 作者在书中警告的失败模式

- 泛泛辩称刑讯逼供而无具体线索（郑某昌案，驳回）。
- 以盖章情况说明替代侦查人员出庭（ce30）。
- 排非调查中宣读供述内容、混淆证据能力与证明力（ce32）。
- 把排非问题转入量刑从宽的"疑罪从轻"降格处理（ce36）。

### 作者的盲点 / 时代局限

- 全书站在审判者立场，未讨论辩方取证难的现实弥补机制；监察案件排非衔接着墨有限。

### 容易混淆的邻近方法论

- "不能排除非法取证"的推定排除，不同于"证据存在瑕疵可补正"——两条通道后果相反。
