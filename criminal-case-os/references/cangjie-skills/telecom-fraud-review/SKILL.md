# 电信网络诈骗及关联犯罪定罪量刑审查

## R — 原文 (Reading)

> "'不特定'是指行为人实施诈骗犯罪时没有明确特定的作案目标；'多数人'是指具有被骗可能性的人达到3人以上。"
>
> — 《刑事审判实务（下册）》第13章第一节

> "只有犯罪嫌疑人、被告人及所在犯罪集团、犯罪团伙的犯罪数额均难以查证时，才应适用第7条的规定。"
>
> — 同书第13章第二节（跨境罪责阶梯）

---

## I — 方法论骨架 (Interpretation)

1. **定性关（点对面双要件）**: 不特定（着手时无明确目标）+多数人（被骗可能性≥3人）。精准诈骗不改变不特定性；点对点网络联络诈骗是传统诈骗，不适用特殊规则。
2. **数额关**: 全国统一标准（3000/3万/50万），不设幅度；2年内多次累计；"接近80%+从重情节"只升严重档、入罪数额不折算。数额难查证时按行为次数折算（信息5000条/电话500人次/浏览5000次，10倍升档；拨打接听均累计、杀猪盘聊天信息不扣）；因被告人隐匿毁灭证据的按已查证日均数综合推算。流水≠犯罪数额，须查证涉诈资金（至少3000元）。
3. **共犯关**: 首要分子按集团全部罪行、主犯按参与或组织指挥的全部；从宽阶梯（从轻减轻→不起诉免刑→不以犯罪论）。
4. **跨境关（三层罪责阶梯）**: 个体数额可查→按数额；集团数额已查证而个体无法查证→综合地位作用、参与时间（宜满30日）、关联度认定，从犯可在数额巨大档量刑；集团与个体数额均无法查证→才可用"1年内出境赴窝点累计30日以上或多次出境"条款（允许正当活动反证，非未遂）。
5. **情节关**: 十种从重四类型；就高定起点、严控缓刑、加强财产刑；胁从犯两反向规则（能自由联络、被胁迫后又积极主动→一般不认定）；"主动/被劝回国投案+如实交代集团整体罪行"=自首。

## A1 — 书中的应用 (Past Application)

### 案例 1: 易某锋、连某仁38人案
- **问题**: 缅甸园区化公司运作集团。
- **方法论的使用**: 集团认定+首要分子按全部罪行。
- **结果**: 无期、十六年，骨干均十年以上。

### 案例 2: 王某洪案
- **问题**: 管理者的犯罪数额。
- **方法论的使用**: 按其负责管理期间的集团诈骗数额（92万中59万）认定。
- **结果**: 按59万余元认定。

### 案例 3: 贾某某案
- **问题**: 未成年人刷单返利39万。
- **方法论的使用**: 特殊主体从宽+家属代为退赔。
- **结果**: 三年缓三年。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 电信诈骗（含杀猪盘、冒充公检法、刷单）案件的定罪量刑与数额认定。
2. 跨境园区案件：窝点认定、30日出境时间推算、胁从犯辩解、回国自首。
3. 诈骗团伙主从犯责任切割与从宽阶梯适用。

### 语言信号

- "杀猪盘案件怎么定数额"
- "境外诈骗窝点30天怎么算"
- "他说被胁迫干的是不是胁从犯"
- "群发短信没骗到钱构成犯罪吗"

### 与相邻 skill 的区分

- 与 `two-cards-crime-line-drawing` 的区别: 供卡、转账行为的罪名选择归后者；本 skill 前提是诈骗罪本体及集团成员责任。
- 与 `organized-crime-review` 的区别: 园区管理型集团按本 skill 认定；只有具备暴力底色+非法控制的才进入涉黑评价。

## E — 可执行步骤 (Execution)

1. **定性**: 核"不特定+多数人"→确定适用文件体系（避免机械套用传统诈骗幅度标准）。
   - 完成标准: 明确本案是否属电信网络诈骗及可适用的特殊规则。
2. **算数额**: 查证涉诈资金（≠流水）；无法查明的按次数/出境时间分层适用；区分首要分子/主犯/从犯责任范围与参与期间。
   - 判停条件: 集团数额已查证的，禁用"30日出境"推定条款。
3. **定情节与量刑**: 从重四类型与从宽阶梯对号；跨境案件审查境外证据转化与刑期折抵（折抵为原则、例外报最高法）；胁从犯辩解必须调查核实。
   - 完成标准: 量刑建议/判决体现宽严两端的政策把握。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 特定人之间点对点的网络联络诈骗（适用传统诈骗规则）。
- 仅供卡、供账户行为的定性（先过 two-cards-crime-line-drawing）。

### 作者在书中警告的失败模式

- 仅凭账户流水认定数额（ce01）。
- 有条件查证个体数额却径用综合认定条款、"30日条款"当未遂规则用（ce03）。
- 办案机关怠于查证却以"客观条件限制"兜底推算（ce03）。

### 作者的盲点 / 时代局限

- 犯罪手法数字化迭代快，规则清单可能滞后；对"回流人员"的社会治理配套未展开。

### 容易混淆的邻近方法论

- 电信诈骗≠涉黑恶：单纯线上催收不具暴力性（见 organized-crime-review 的软暴力边界）。
