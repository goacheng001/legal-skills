# 疑罪从无操作流程

## R — 原文 (Reading)

> "疑罪从无是指在刑事诉讼中……在既确定不了被追诉人实施了犯罪，也排除不了被追诉人实施了犯罪的情况下，应当认定被追诉人无罪。" "定罪事实存疑则从无，量刑事实存疑则作有利于被告人的认定。"
>
> — 第一章第四节 疑罪从无原则

## I — 方法论骨架 (Interpretation)

疑罪从无不是"觉得可疑就放人"，而是带三重门槛的责任判断。门槛一：**真伪不明**——排除合理怀疑不能，且区别于"有证据证明无罪"的事实无罪。门槛二：**取证穷尽**——能补查、能补充侦查的先补查，不得跳过。门槛三：**责任定位**——疑罪本质是控方未完成法定证明责任，裁判认定疑罪必须围绕证明责任与证明标准说明理由（证据之间、证据与事实之间的矛盾，结论不唯一）。处理端二分：定罪事实存疑（罪与非罪/此罪彼罪/一罪数罪）→宣告无罪或不予认定；量刑事实存疑→就低认定。死刑案件适用最严版本：定罪或量刑证据不能得出唯一结论的，绝对不适用死刑。口供依赖型案件还要先过非法证据排除——口供被排且无其他证据锁定被告人时，必须坚决从无。

## A1 — 书中的应用 (Past Application)

### 案例 1: 陶某故意杀人案
- **问题**: 情人同宿遇害，被告人不报案离开且曾自认又翻供。
- **使用**: 疑点清单检验：真伪不明+取证穷尽→疑罪从无。
- **结果**: 宣告无罪；两年后真凶归案。

### 案例 2: 陈某雄运输毒品案
- **问题**: 有罪供述合法性、真实性存疑。
- **使用**: 先排除非法口供→被告人对反常行为能合理解释→明知存疑→无罪。
- **结果**: 宣告无罪（案例库 2023-06-1-356-048）。

## A2 — 触发场景 (Future Trigger) ★

1. 合议庭评议中"证据链条差一环"，争论能否定罪。
2. 口供系定案支柱，辩护人申请排除或供述反复。
3. 部分事实清楚、部分存疑，需要决定部分无罪/不予认定。
4. 量刑情节（自首、主从、数额）证据冲突，需要就低认定。
5. 死刑案件复核审的证据把关。

语言信号: "能不能定""排除合理怀疑了吗""证据不足宣告无罪""疑罪从无""就低认定"。

### 与相邻 skill 的区分（初稿）
- 与 `interpretation-scope-check`: 那个是法律解释之争；本 skill 是事实证明之争。

## E — 可执行步骤 (Execution)

1. **区分疑罪与事实无罪**: 是否存在证明被告人无辜的证据？有→径行无罪（非疑罪从无）；无→进入下一步。
   - 完成标准: 案件归入"事实无罪/疑罪/证据充分"三类之一。
2. **穷尽取证检查**: 是否仍有可补充侦查、依职权调查的关键事实？有→先补查，判停。
   - 完成标准: 补查可能性已排查并记录。
3. **矛盾点清单**: 列出证据与证据、证据与事实之间的矛盾，检验结论是否唯一。
   - 完成标准: 形成"结论唯一/不唯一"判断及矛盾清单。
4. **二分处理**: 定罪事实存疑→无罪或部分不予认定；量刑事实存疑→就低。
   - 完成标准: 裁判主文与说理按二分公式落地。
5. **说理责任化**: 以控方证明责任未完成+证明标准为轴撰写疑罪认定理由。
   - 完成标准: 文书有专门段落回应。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 仅量刑事实争议（用"就低"而非无罪）；程序违法（转程序性制裁处理）。

### 书中警告的失败模式
- 把疑罪等同于证据有瑕疵——瑕疵可补正的不构成疑罪。
- 因被告人翻供、辩解才去认定疑罪——疑罪不以翻供为前提，笼统认罪但供述真实性无保障同样可能构成疑罪。
- 程序空转：事实不清一味发回重审。

### 作者盲点
- 书承认"落实疑罪从无仍有困难"但未给出面对外部压力时的程序保护方案。

### 容易混淆的邻近方法论
- 存疑不起诉（审查起诉阶段）与疑罪从无判决（审判阶段）的分工。
