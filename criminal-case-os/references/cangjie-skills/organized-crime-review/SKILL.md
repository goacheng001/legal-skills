# 涉黑恶案件认定与财产处置

## R — 原文 (Reading)

> "只有在齐备四个特征的情况下，才能认定为黑社会性质组织犯罪，不能以其中某一个特征突出、典型为由，忽略对其他特征的审查判断，直接认定为黑社会性质组织。"
>
> — 《刑事审判实务（下册）》第15章第一节

> "有证据证明其在犯罪期间获得的财产高度可能属于黑社会性质组织犯罪的违法所得及其孳息、收益，被告人不能说明财产合法来源的，应当依法予以追缴、没收。"（引《反有组织犯罪法》第45条第3款）
>
> — 同书第15章第三节

---

## I — 方法论骨架 (Interpretation)

1. **四特征逐项闸门（缺一不可）**: 组织特征（骨干基本固定+持续存在，以核心成员与非法影响的延续性判断中断案件）；经济特征（利益客观上豢养成员、维稳、壮大——"坐地分赃"式支配不算）；行为特征（暴力威胁为底色，软暴力须以暴力现实可能性为基础并达心理强制，"不胜其烦"不算；一般应有违法犯罪多样性）；危害性特征（核心——区域或行业非法控制/重大影响，区分个案影响与组织影响，程度逐项查"多少群众、多长时间、多少次"）。
2. **恶势力（雏形）**: 一般3人以上+纠集者相对固定+2名相同成员多次参与+2年内经常纠集；暴力威胁为主要手段+公开性；3次以上含1次犯罪；"为非作恶、欺压残害群众"（事出有因排除）；危害多重性。2人恶势力仅限极个别；全员未成年/老年/残疾的特别慎重。
3. **套路贷**: 非法占有目的+五类套路形成虚假债权债务；罪名按取得手段分流（骗→诈骗、威胁要挟→敲诈、当场劫取→抢劫）；数额=本金外全部名目；自愿接受砍头息=高利放贷；套路贷≠必然黑恶；仅以诉讼仲裁公证讨债不具暴力特征。
4. **涉黑财产"高度可能性"六条件闭合**: 定罪量刑事实查清+期间获取证据+证据未达确实充分+公诉方举证（标准介于优势证据与排除合理怀疑间）+常情常理合法收入不足+辩解不成立。

## A1 — 书中的应用 (Past Application)

### 案例 1: 符某某等人案
- **问题**: 谈判协商+堵路揽工程，获利坐地分赃。
- **方法论的使用**: 行为特征（避损非恐惧）+经济特征双不符。
- **结果**: 不认定黑社会性质组织。

### 案例 2: 龚某文案（指导案例186号）
- **问题**: 软暴力为主的讨债组织。
- **方法论的使用**: 软硬交织、随时转化→心理强制成立。
- **结果**: 行为特征具备。

### 案例 3: 汪某案
- **问题**: 头目受伤致活动中断5年。
- **方法论的使用**: 核心成员延续性+非法影响延续性→持续存在。
- **结果**: 可认定组织持续。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 涉黑恶案件的罪名认定审查、上诉申诉中对四特征的攻防。
2. 催收、讨债公司案件的恶势力判定与出罪。
3. 民间借贷纠纷与套路贷的刑民界分；涉黑财产的追缴没收审查。

### 语言信号

- "这够不够黑社会性质组织"
- "能不能定恶势力"
- "套路贷和高利贷怎么区分"
- "他亲属名下的财产要不要没收"

### 与相邻 skill 的区分

- 与 `telecom-fraud-review` 的区别: 园区管理型跨境诈骗集团按后者认定（外部管控型）；本 skill 处理以自身实施违法犯罪为内容的组织。
- 与 `criminal-procedure-review` 的区别: 涉黑财产的"高度可能性"实体标准在本 skill；查扣冻的程序处置归后者。

## E — 可执行步骤 (Execution)

1. **过四特征**: 逐特征独立审查并记录证据，禁止以一特征突出带过；对照传销、恐怖组织排除。
   - 判停条件: 任一特征不成立→整体不认定，转普通罪名处理。
2. **恶势力降格判断**: 不满足黑社会组织但符合三特征的定恶势力；核查"2人""未成年人""打包凑数"情形。
   - 完成标准: 有/无恶势力标签的明确结论。
3. **套路贷专项**: 非法占有目的+套路手法→罪名分流→数额计算。
4. **财产处置**: 六条件逐项检验"高度可能性"；防止以"较大可能"没收、防止证据已充分仍绕行该标准。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 仅线上实施、无暴力及暴力现实可能性的犯罪集团（电诈、裸聊敲诈等按相应罪名）。
- 有违法犯罪行为的单位（有正当经营范围、违法所得非主要收入）。

### 作者在书中警告的失败模式

- "沾边就算"、拔高凑数（ce12）；软暴力泛化、纯线上定涉黑（ce14）；恶势力打包叠加（ce15）；套路贷必然黑恶（ce16）；"高度可能性"降为"较大可能"（ce17）。

### 作者的盲点 / 时代局限

- 专项斗争语境下的从严倾向需要以罪刑法定平衡；对"摘帽"后企业善后、涉案企业合规未涉及。

### 容易混淆的邻近方法论

- 恶势力≠黑社会性质组织（程度差异）；管理控制型园区集团≠黑社会组织（对象是团伙而非公众）。
