# 跨境电商渠道走私定性审查

## R — 原文 (Reading)

> "可从行为性质（是否伪报贸易性质，逃避海关监管）、危害后果（是否实际造成国家税款流失）两个方面，审慎判断是否必须纳入刑事打击范围。"
>
> — 第七章第一节 跨境电商零售进口渠道走私的定性问题

## I — 方法论骨架 (Interpretation)

审查走两步。**第一步，伪报贸易性质判断**——核心是有无二次交易、真实交易模式是否 B2C。"刷单"走私：虚构或冒用消费者身份、本应一般贸易进口的货物经电商渠道进来后转售牟利，实质 B2B2C，属伪报贸易性质，构成走私普通货物罪。"推单/引流"：消费者真实自用购买、仅订单事后导入与海关联网平台，权属直接从境外经营者转到境内消费者、无二次交易——本质仍是 B2C，与刷单难以类比；"海淘转运"同属一条交易链，不因经转运公司中转就形成两段贸易关系。**第二步，税款流失判断**——纳税义务人是国内消费者，判断重点在实际占用消费者个人年度/单次优惠额度、商品在清单范围内；平台备案、三单对碰等形式要件主要服务监管便利，不宜作为优惠资格的决定性因素，也不宜简单以一般贸易税差倒算偷逃额。两步之外还有一层**谦抑过滤**：新业态不规范行为与传统走私在罪质、危害上不相当的，优先行政治理、监管堵漏。

## A1 — 书中的应用 (Past Application)

### 案例 1: 刷单走私的认定逻辑
- **问题**: 组织他人身份信息批量下单、入境后转售。
- **使用**: 无真实境内消费者+二次交易+B2B2C→伪报贸易性质。
- **结果**: 构成走私普通货物罪。

### 案例 2: 推单行为的区别对待
- **问题**: 消费者真实下单境外网站，平台/服务商将订单导入联网平台申报。
- **使用**: 两步审查：真实B2C+实际占用个人额度→不属伪报贸易性质，税款流失结论亦存疑。
- **结果**: 不宜径行刑事打击，谦抑处理。

## A2 — 触发场景 (Future Trigger) ★

1. 代购、海淘转运、跨境电商平台"推单"业务被海关立案。
2. 离岛免税品"套代购"与亲友代买的区分。
3. 偷逃税额计算方法（按一般贸易还是行邮税基准）之争。
4. 平台、商家、消费者多主体的责任切割。

语言信号: "刷单走私""推单违不违法""代购算走私吗""伪报贸易性质""套用免税额度"。

### 与相邻 skill 的区分（初稿）
- 与 `regulatory-crime-review`: 共用前置法与谦抑方法；本 skill 是走私领域的专门两步检验。

## E — 可执行步骤 (Execution)

1. **交易链还原**: 下单主体、支付流、物流路径、商品权属转移、有无二次销售。
   - 完成标准: 交易链图（含各主体角色）完成。
2. **伪报判断**: 有无二次交易、真实模式 B2C/B2B2C、消费者是否真实自用。
   - 完成标准: 伪报/非伪报结论。
   - 判停: 非伪报→一般不构成走私，转行政违规评估。
3. **税款流失核算**: 优惠资格要件（清单/限额/个人额度实际占用）逐项核对，合理确定计税基准。
   - 完成标准: 偷逃应缴税额及算法说明。
4. **谦抑评估**: 与传统走私的罪质相当性、行为普遍性与政策背景。
   - 完成标准: 入罪必要性的明确论证。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 传统报关单证造假（伪报品名/低报价格/夹藏）——直接按走私审查，无需本框架。

### 书中警告的失败模式
- 把"推单"简单类比"刷单"。
- 以平台未备案等形式违规直接推定税款流失。

### 作者盲点
- 规则针对 2025 年前的政策形态（单次5000元/年度26000元限值），税制调整后需动态更新。

### 容易混淆的邻近方法论
- 离岛免税"套代购"属"化整为零"型伪报，与推单的定性方向相反——先分清政策类型再套用本框架。
