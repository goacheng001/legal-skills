# 速裁程序适用与转换审查

## R — 原文 (Reading)

> "适用速裁程序审理案件，虽无法庭调查和法庭辩论环节，但审判人员仍应当庭询问被告人对指控的证据有无异议，被告人无异议的，即应当视为经过了庭审质证程序。"
>
> — 《刑事审判实务（下册）》第21章第二节

> "只要有一名被告人对上述内容有异议，就不能适用速裁程序。"
>
> — 同书第21章第二节（共同犯罪排除情形）

---

## I — 方法论骨架 (Interpretation)

速裁是一道"入口闸门＋出口闸门"的程序：

**入口三条件**: 基层法院管辖且可能判处三年有期徒刑以下；事实清楚、证据确实充分（适用前须实质审查证据）；被告人认罪认罚并同意适用。
**入口七类排除**: 盲聋哑人或未完全丧失辨认控制能力的精神病人；未成年人（按审判时年龄）；重大社会影响；共同犯罪中任一被告人对事实/罪名/量刑建议/程序有异议；与被害方未达成附带民调解和解（被害方无法查找或未提起的不在此列）；辩护人作无罪辩护；其他不宜。
**审理要点**: 独任；庭审重心=核实三性+询问证据异议；判前必听辩护人意见和最后陈述；应当当庭宣判；不受送达期限限制（开庭前通知即可）；审限10日（可能判处超过一年有期徒刑的15日——指最低刑超一年）；一般不提交审委会；检察院未建议的，法院可依职权决定适用，不必重回具结签署。
**出口转换**: 审理中发现不构罪/不应追责/违背意愿/否认事实/疑难复杂/其他不宜→转普通或简易重新审理；速裁已审结的走审判监督程序。

## A1 — 书中的应用 (Past Application)

### 案例 1: 法答网速裁上诉问题
- **问题**: 速裁案件以事实不清证据不足上诉，二审发回重审按普通程序、不再按认罪认罚从宽处罚，能否加刑。
- **方法论的使用**: 上诉不加刑总标准——"取消从宽待遇后实质更重即违法"。
- **结果**: 不得加重刑罚（另见入库案例李某明等故意伤害案同旨）。

### 案例 2: 适用范围扩大沿革
- **问题**: 速裁试点从一年以下扩到三年以下。
- **方法论的使用**: 以认罪认罚为条件扩大范围，同时以七类排除守住权利底线。
- **结果**: 2018年速裁程序法定化。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分案/收案时判断案件走速裁、简易还是普通程序。
2. 速裁庭审中发现疑点、被告人翻供或辩护人做无罪辩护，需要转程序。
3. 速裁案件上诉后的程序与量刑处理。

### 语言信号

- "这个案子能用速裁吗"
- "速裁转普通程序要不要重新开庭"
- "速裁案件上诉会不会被加刑"
- "速裁十日审限怎么算"

### 与相邻 skill 的区分

- 与 `plea-lenient-review` 的区别: 速裁的实体（认罪认罚认定、量刑建议）归后者；本 skill 只管程序闸门。
- 与 `courtroom-substantiation` 的区别: 速裁不走普通庭审的法庭调查辩论；其简化规则由本 skill 承载。

## E — 可执行步骤 (Execution)

1. **过入口闸门**: 逐项核对三条件；逐项核对七类排除（尤其共同犯罪"一人异议全案排除"、盲聋哑人、未成年人）。
   - 判停条件: 任一排除情形成立→转简易/普通路径。
2. **组织速裁庭审**: 送达从简但开庭前通知；庭审=三性核实+证据异议询问+附带民情况；判前听辩护人意见和最后陈述；当庭宣判。
   - 完成标准: 庭审笔录载明三性核实内容。
3. **处理转换与上诉**: 发现不宜情形→转程序重新审理；上诉发回重审的→取消从宽重新量刑但不得重于原判。
   - 完成标准: 程序转换裁定/重审判决符合上诉不加刑。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 案件可能判处超过三年有期徒刑、或由中院以上管辖——速裁无适用余地。
- 被告人认罪但不认罚——只能走简易或普通程序。

### 作者在书中警告的失败模式

- 效率滥用：不核实三性即宣判、省略最后陈述、有一人异议仍用速裁、把速裁案提交审委会（ce48）。
- 以牺牲被害人权利换取快审（附带民未调解即速裁）。

### 作者的盲点 / 时代局限

- 对"技术性上诉"的制度回应仅停留在不得加刑的立场宣示，未提供激励机制设计；集中审理、集中宣判对被告人个别化审理的影响未展开。

### 容易混淆的邻近方法论

- 速裁≠简易：审判组织、调查辩论、审限、认罚要求四点差异。
